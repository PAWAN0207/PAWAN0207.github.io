# Pawan Ajay Prasad — AI Engineer Portfolio

Personal portfolio for Pawan Ajay Prasad, focused on Generative AI, RAG, Machine Learning, Data Analytics and practical AI engineering.

## Publish on GitHub Pages

1. Create a public repository named `PAWAN0207.github.io`.
2. Upload the contents of this folder to the repository root.
3. Confirm `index.html`, `styles.css`, `script.js`, and the `assets/` folder are directly in the root.
4. Go to **Settings → Pages**.
5. Set **Source** to **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Open `https://pawan0207.github.io/` after deployment finishes.
