## Deploy to GitHub Pages
1. Create/use the repository `PAWAN0207.github.io`.
2. Upload the contents of this folder to the repository root (not the outer folder itself).
3. Confirm `index.html` is in the repository root and `assets/profile.jpg` plus `assets/Pawan_Ajay_Prasad_Resume.pdf` exist.
4. In Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Open `https://pawan0207.github.io/` after the deployment completes.
